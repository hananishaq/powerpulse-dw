# Step 3 (part 1) — Warehouse schema

**Owner:** ________ · **Marks:** Database Implementation, Surrogate Keys · **Needs first:** Step 1

## Your job
Create the seven `project_dw` tables exactly as designed in Phase 1.

## Create these files
- `00_create_dimensions.sql` — `dim_date`, `dim_hour`, `dim_balancing_authority`, `dim_energy_source`, `dim_source_snapshot`.
- `01_create_facts.sql` — `fact_hourly_demand`, `fact_hourly_generation`.

## Rules
- Names and all 50 columns come from `docs/phase2/name_mapping.csv`; data types and nullability from `docs/phase1/07_Data_Dictionary.xlsx`; diagram in `docs/phase1/06b_Schema_ERD.png`.
- Surrogate primary keys: `bigint GENERATED BY DEFAULT AS IDENTITY`.
- UNIQUE constraint on every natural/business key. Facts: unique on (`authority_key`, `utc_hour_end`) and (`authority_key`, `utc_hour_end`, `energy_source_key`).
- Foreign keys are `NOT NULL` and reference the dimension PKs.
- Scripts must be re-runnable (`CREATE TABLE IF NOT EXISTS` or drop-and-create in a clearly marked reset script).

## Done when
`\dt project_dw.*` shows 7 tables and a foreign-key diagram in pgAdmin matches the ERD.
**Push this early — Steps 4 and 5A need these tables.**
