# Acquisition and profiling

Requires Python 3.10 or newer; both scripts use only the standard library. No EIA API key is required for the official bulk download route.

Open a terminal in this folder. On Windows, replace `python` with `py` if necessary.

```sh
python download_data.py
python profile_data.py
```

The default selection is CISO, ERCO, ISNE, NYIS and PJM; years 2024 and 2025; both six-month files each year. Downloads are cached under `cache/`. The four full CSV files total approximately 185 MB. The delivered `data/` folder already contains the selected rows, original fields and source row lineage. Full original CSVs are not duplicated in this package; the script reacquires them from the official URLs.

The acquisition script records URLs, retrieval timestamps, SHA-256 hashes, full row counts and subset hashes in `data/source_manifest.json`. The reference workbook is also downloaded. A normal rerun validates and reuses cached files. To fetch a changed source deliberately, use `--refresh`; preserve the delivered baseline in a different folder when refreshing.

Example of acquiring a separate newer snapshot of a single existing period:

```sh
python download_data.py --years 2025 --halves Jul_Dec --refresh --out refreshed_data --cache refreshed_cache
python profile_data.py --data refreshed_data
```

See each script's `--help` for options. Profiling verifies subset hashes, measures observed coverage and missing values, detects duplicate UTC keys and repeated local hour labels, inventories reported fuel headers and checks available-fuel reconciliation. It writes `profile.json` and a 20-row sample. These are source profiling outputs, not ETL or a populated warehouse.

The selected CSVs preserve all publisher columns. Only unsuffixed reported demand, forecast, total generation and reported fuel headers belong to the Phase 1 model. Imputed and adjusted source variants are not silently mixed with reported values.

`authority_reference.csv` and `energy_source_mapping.csv` are design reference exports generated by the report builder from the official reference workbook and measured profile. Their source meaning and mapping rules are documented in the dictionary. Source row numbers identify the CSV data record, excluding the header.
